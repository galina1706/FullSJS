## Інтерактивні елементи

- **Бургер-меню.** На екранах до 1024px меню відкривається панеллю на весь екран. Закривається хрестиком, клавішею Esc або після переходу за посиланням. Поки меню відкрите, сторінка не прокручується.
- **Таби.** Один компонент для напрямів і днів тижня. Працює з клавіатури (стрілки, Home, End), має ARIA-ролі `tablist`, `tab`, `tabpanel`.
- **Слайдер тренерів.** Побудований на `scroll-snap`, тому на телефоні гортається свайпом. Кнопки «назад» і «вперед» вимикаються на краях, крапки-індикатори перераховуються при зміні розміру вікна (1, 2 або 3 картки на екран).
- **Фільтр розкладу.** Ховає заняття інших напрямів у всіх днях і показує повідомлення, якщо в день нічого не лишилось.
- **Акордеон FAQ.** Нативні `<details name="faq">`: одночасно відкрите лише одне питання, працює навіть без JS.
- **Форма запису.** Валідація полів з підказками під полями, після успішної відправки з'являється повідомлення з ім'ям.
- **Поява блоків при прокрутці** через `IntersectionObserver`. Вимикається, якщо в системі ввімкнено «зменшити рух».

## SCSS

Стилі розбиті на partials за архітектурою 7-1 (спрощеною) і зібрані через модульну систему `@use` / `@forward`:

```
scss/
├── abstracts/
│   ├── _variables.scss   # кольори, шрифти, радіуси, тіні, брейкпоінти (map)
│   ├── _functions.scss   # rem(): переводить px у rem
│   ├── _mixins.scss      # mq(), mq-down(), card(), button-variant(), flex-center, visually-hidden, hide-scrollbar
│   └── _index.scss       # @forward усіх abstracts
├── base/                 # reset, типографіка
├── layout/               # container і секції, header, footer
├── components/           # button, tabs, slider, accordion, form, reveal
├── pages/                # home, schedule
└── main.scss             # точка входу
```

Особливості:

- **Змінні** для всієї палітри та розмірів, брейкпоінти зберігаються в map `$breakpoints`.
- **Міксини** `mq(md)` і `mq-down(lg)` для медіа-запитів, `button-variant()` генерує всі варіанти кнопок, `card()` дає однаковий вигляд карткам.
- **Вкладення та BEM**: `.trainer { &__name {} &__role {} }`, модифікатори `--featured`, `--alt`, `--compact`.
- **Mobile-first**: базові стилі для телефону, далі `mq(sm)` 576px, `mq(md)` 768px, `mq(lg)` 1024px.
- Плавні розміри заголовків через `clamp()`.

## Доступність

- Посилання «Перейти до вмісту» для клавіатури.
- Видимий фокус (`:focus-visible`) на всіх інтерактивних елементах.
- `aria-expanded`, `aria-controls`, `aria-selected`, `aria-pressed`, `role="status"` для динамічних елементів.
- `prefers-reduced-motion`: анімації та плавна прокрутка вимикаються.
- У всіх зображень є `alt`, `width` і `height` (без стрибків верстки під час завантаження).

## Запуск

Готовий CSS (`css/main.css`) вже лежить у репозиторії, тож сайт можна відкрити одразу: `index.html` у браузері або через Live Server у редакторі.

Щоб змінювати стилі:

```bash
cd HW_17.1
npm install
npm run dev     # sass --watch: перезбирає css/main.css при кожній зміні
npm run build   # мінімізована збірка для публікації
```

## Тестування та валідація

```bash
npm test        # = npm run lint:html && npm run lint:css
```

- **HTML** перевірено [html-validate](https://html-validate.org/) з набором `html-validate:recommended`: 0 помилок.
- **SCSS** перевірено [Stylelint](https://stylelint.io/) з `stylelint-config-standard-scss`: 0 помилок.
- **Адаптивність** перевірено на ширинах 390px (телефон), 768px (планшет) і 1440px (десктоп): горизонтальної прокрутки немає, меню, таби, слайдер і фільтр працюють.
- **Браузери**: перевірено в Chrome; код розрахований на сучасні Chrome, Edge, Firefox і Safari (використано `scroll-snap`, медіа-запити з синтаксисом `width >=`, властивість `translate`). Ексклюзивний акордеон (`details name`) у старих браузерах просто дозволяє відкрити кілька питань одночасно.
