# CSS Selectors & Specificity Demo

Навчальний веб-проєкт, який демонструє роботу **CSS-селекторів** та принцип
розрахунку їхньої **ваги (специфічності)**. Проєкт складається з простої
HTML-сторінки та підключеного до неї файлу стилів, у якому кожне правило
побудоване на окремому типі селектора.

## 🎯 Що робить проєкт

- Показує 10 елементів на сторінці, кожен з яких стилізується власним
  CSS-правилом і має унікальний колір фону.
- Для кожного правила в розмітці вказано **текстовий опис селектора та
  розрахована вага (специфічність)**.
- Демонструє, як браузер визначає, яке саме правило застосувати до
  елемента, коли на нього претендує кілька селекторів (каскад +
  специфічність).

## ⚙️ Функціональні можливості

- Приклади всіх основних видів селекторів:
    - тег (`span`)
    - клас (`.highlight`)
    - ідентифікатор (`#special`)
    - атрибут (`[title]`)
    - вкладені / нащадкові селектори (`article p`)
    - дочірні селектори (`div > p`)
    - послідовність (складений) селектор (`li.active`)
    - комбінації тег + клас + id + атрибут + вкладеність
- Кожне правило супроводжується коментарем у `style.css` з розрахунком ваги.
- HTML і CSS проходять валідацію через офіційні валідатори W3C.

## ✨ Особливості реалізації

- Вага селекторів рахується за простою адитивною системою, прийнятою у
  курсі: **тег = 1, клас/атрибут/псевдоклас = 10, id = 100**.
- Приклад `div > p` (вага 2) відповідає технічному завданню один-в-один —
  і текст усередині тега, і сам селектор.
- Код мінімалістичний: жодного зайвого тексту, який не описує селектор
  або його вагу.

## 📁 Структура файлів

```
├── index.html   — розмітка з 10 елементами
├── style.css    — 10 CSS-правил різних типів селекторів
└── README.md    — опис проєкту
```
